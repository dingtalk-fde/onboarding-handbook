# Buddy 与导师制度

> 文档负责人：人力资源部 刘畅｜最近更新：2026-06-15

## Buddy（入职伙伴）

每位新人入职时都会被分配一名 Buddy，由直属上级在新人入职前一周指定。

- **谁可以做 Buddy**：同团队、入职满 1 年、最近一次绩效“符合预期”及以上的同事。
- **职责期限**：新人入职后前 **3 个月**。
- **职责**：
  - 入职第一天带新人熟悉环境、介绍团队成员
  - 日常答疑：“这个系统在哪里”“这个流程找谁”
  - 每周至少一次 15–30 分钟的非正式聊天（可以一起吃午饭）
  - 帮新人把权限申请、环境配置等琐事推进下去
  - 在转正评估时提供“价值观”和“融入”方面的反馈
- **激励**：Buddy 每带一名新人，可获得 500 元“伙伴奖励”（新人转正后随当月工资发放），并计入年度绩效的“团队贡献”。

## 导师（Mentor）

- 导师关注**业务与能力成长**，通常由直属上级本人或其指定的资深同事（P7 及以上）担任。
- 导师负责：制定 30/60/90 计划、技术/业务方向指导、评审新人的关键产出。
- Buddy 和导师可以是同一个人，但我们更建议分开，让新人有两个不同的求助渠道。

## 如果 Buddy 不合适

如果 Buddy 长期不回复、或你感到沟通不畅，可以直接告诉直属上级或 HRBP 申请更换，不需要任何理由，也不会影响任何人的评价。

## 常任 Buddy 示例

技术中心有几位同事长期担任 Buddy，新人遇到跨团队问题也可以找他们：
- 陆一凡（CRM 后端组，后端开发环境、Java 相关）
- 叶知秋（CRM 前端组，前端工程与设计系统）
- 高远（SRE 组，帆舟发布、K8s、监控）
