# 入职第一天清单（Day 1 Checklist）

> 文档负责人：招聘与入职专员 林小满｜最近更新：2026-09-10

## 报到时间与地点

- **时间**：入职当天 **9:30** 到达（比平时早，方便办理手续）。
- **地点**：杭州总部 8F 前台（北京、深圳同事到各自办公室前台，由罗佳 / 莫晓蕾接待）。
- 入职日一般为**周一**；如遇节假日顺延至下一个工作日。

## 需要携带的材料

1. 身份证原件
2. 学历、学位证书原件（应届生携带《就业报到证》或学校证明）
3. 上一家单位的**离职证明**原件（应届生无需）
4. 近 3 个月内的**入职体检报告**（三甲医院或公司指定体检机构，费用可报销，上限 300 元）
5. 本人名下**招商银行**储蓄卡（工资卡）；没有的话入职一周内补办即可
6. 1 寸白底证件照电子版（用于工牌，提前发给林小满）

## 上午：手续办理（9:30–12:00）

| 时间 | 事项 | 对接人 |
|------|------|--------|
| 9:30 | 前台签到，领取访客卡 | 前台 |
| 9:45 | 签署劳动合同、保密协议（NDA）、《员工手册》确认书、知识产权归属协议 | 林小满 |
| 10:30 | 领取电脑、显示器、键鼠，现场开机激活 | IT 何小川（8F IT 服务台） |
| 11:00 | 激活钉钉、企业邮箱、SailGate VPN，设置 MFA | IT 何小川 |
| 11:30 | 领取工牌（门禁卡）、工位分配、储物柜钥匙 | 行政 曹敏 |

> 劳动合同标准期限为 **3 年**，试用期 **6 个月**，详见[试用期与转正](probation.md)。

## 下午：认识团队（13:30–18:00）

- 13:30 直属上级接你到工位，介绍团队成员和 **Buddy**（入职伙伴，见 [Buddy 与导师制度](buddy-mentor.md)）
- 14:00 新人第一次 1:1：上级介绍团队目标、你的岗位职责和试用期目标的初步方向
- 15:00 Buddy 带你熟悉办公区：茶水间、会议室、母婴室、健身房（11F）、快递柜（1F 大堂）
- 16:00 自主完成钉钉“学习”中的必修课：《信息安全入门》《员工手册要点》（共约 60 分钟，**入职 3 天内必须完成**）
- 17:00 在团队群做个简短自我介绍（可以说说爱好）

## 第一天结束前请确认

- [ ] 钉钉已激活，能看到通讯录和所在部门群
- [ ] 企业邮箱能收发邮件，邮件签名按[沟通规范](../07-communication/communication-norms.md)设置
- [ ] SailGate VPN 已安装并完成 MFA 绑定
- [ ] 已加入钉钉群“云帆新人营（2026Q4）”
- [ ] 工牌能刷开所在楼层门禁
- [ ] 知道直属上级、Buddy、HRBP 分别是谁
- [ ] 已在钉钉“考勤打卡”中确认考勤组（默认“杭州弹性工时组”）

有任何问题，先问 Buddy；手续类问题找林小满（钉钉 / xiaoman.lin@nebulasail.example / 分机 8102）。
