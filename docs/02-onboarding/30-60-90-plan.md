# 30 / 60 / 90 天计划

> 每位新人都需要在入职第一周与直属上级共同确定 30/60/90 天计划，写在钉钉“试用期目标”模板中。该计划是[试用期评估](probation.md)的重要依据。

## 通用框架

| 阶段 | 关键词 | 目标 |
|------|--------|------|
| 第 1–30 天 | **学习** | 熟悉业务、客户、NAP 与流程；完成必修课和安全考试 |
| 第 31–60 天 | **贡献** | 在指导下承担客户项目中的具体模块并上线 |
| 第 61–90 天 | **独立** | 独立负责一个客户的一个 Agent 或一个平台模块 |

## FDE 示例（服饰美妆 FDE 组，P6）

**30 天**
- 在 NAP 测试环境独立搭建客服 Agent Demo（RAG + 订单查询工具 + Guardrail），NEval 评测通过率 ≥ 85%
- 完成 3 个以上客户 Badcase 修复（Prompt 或知识库优化）并通过回归评测上线
- 随资深 FDE 陆一凡完成一次客户驻场（旁听 Discovery 或上线保障）

**60 天**
- 在一个客户项目中负责一个完整模块（例如“退换货政策问答”或“尺码推荐”），从评测集构建到灰度上线
- 作为 Reviewer 参与至少 10 个 MR / Prompt 变更评审
- 加入 On-call “影子值班”一周

**90 天**
- 成为一个客户 Agent 的 FDE Owner，负责周度效果报告
- 正式进入 On-call 轮值
- 在组内做一次分享（例如“大促前客服 Agent 压测与降级方案”）

## Agent 平台研发示例（P6）

- **30 天**：读完 NAP 架构文档，修复 3 个平台缺陷；为一个连接器补齐单元测试
- **60 天**：独立完成一个中等需求（例如抖店新售后接口接入）并上线
- **90 天**：成为一个平台模块 Owner（例如“拼多多连接器”）

## SA / 产品示例

- **30 天**：跟随 2 个 Discovery，输出一份行业流程梳理（例如“食品类目售后场景地图”）
- **60 天**：独立设计一个 PoC 方案和验收评测集，通过方哲评审
- **90 天**：负责的 PoC 完成验收或给出清晰的不推进结论

## 销售示例

- **30 天**：通过产品与平台规则认证；跟随资深销售拜访 8 家商家/服务商
- **60 天**：独立推进 5 个有效商机，至少 1 个进入 PoC
- **90 天**：首单签约（或达成季度目标的 30%）

## 检查节点

- 第 30、60 天：与直属上级 1:1 回顾，更新“试用期目标”进展
- 第 90 天：**中期评估**，上级 + HRBP 刘畅参与，给出“符合预期 / 需改进”结论
- 不符合预期时，上级须制定书面改进计划（PIP），期限通常为 4–6 周
