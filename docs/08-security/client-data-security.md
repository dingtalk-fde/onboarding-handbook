# 客户数据安全与驻场安全规范

> 文档负责人：信息安全负责人 白冰、安全工程师 周子涵、法务经理 杜明哲｜最近更新：2026-10-01｜入职 1 周内必须完成本规范对应的课程与考试

## 为什么这很重要

我们的 Agent 每天处理客户店铺的商品、订单、售后和消费者对话。一次数据泄露可能让客户被电商平台处罚（下架、封店）、让公司失去所有客户信任，并承担法律责任。**客户数据安全是 RN 的生命线。**

## 一、电商平台合规环境

| 平台 | 合规环境 | 规则要点 |
|------|----------|----------|
| 淘宝 / 天猫 | **聚石塔** | 订单、消费者数据必须在聚石塔内处理和存储，不得同步到聚石塔外 |
| 京东 | **京东云鼎** | 同上，访问需通过云鼎堡垒机 |
| 抖音电商 | 抖音电商云（抖店云） | 同上 |
| 拼多多 | 多多云 | 同上，订单收件人信息平台侧已加密，禁止尝试解密 |

- 处理平台订单数据的 Agent 组件（订单查询、物流、售后工具）必须部署在对应的合规环境中。
- 平台 AppKey / AppSecret / Access Token 只存放在 KMS，由连接器调用；任何人不得把它们写进代码、Prompt、文档或聊天。

## 二、大模型使用规则

1. 所有模型调用**必须经过模型网关**，网关会对手机号、地址、姓名、订单号等做脱敏和审计。
2. 禁止直接调用外部模型 API，禁止使用个人账号的 AI 工具处理客户数据。
3. 客户 DPA 约定了可用的模型供应商范围（部分客户要求只用国内模型或私有化模型），FDE 配置 Agent 时必须遵守。
4. 客户数据**不用于训练或微调**，除非客户书面授权并经白冰审批。

## 三、客户之间的隔离

- 每个客户独立租户、独立代码仓库、独立知识库；禁止跨租户查询。
- 禁止把 A 客户的数据、Prompt、截图、案例直接用于 B 客户（包括在售前演示中展示）。对外案例展示需客户书面授权，由 CSM 办理。
- 评测集复用必须去除客户标识，经白冰审核。

## 四、驻场安全要求

- 出发前完成驻场安全交底（周子涵，15 分钟）。
- 使用公司电脑（磁盘加密、EDR 开启），客户要求使用其设备时按客户规定执行，**不得把客户设备上的数据转移到公司或个人设备**。
- 客户提供的系统账号（ERP、千牛/京麦子账号等）仅限本人使用，在钉钉“客户账号登记”中登记，离场当天提交注销申请。
- 遵守客户的门禁、拍照、保密规定；**禁止拍摄客户屏幕和办公环境**发到任何群（包括公司内部群）。
- 客户要求签署个人保密承诺：先发给法务杜明哲确认后再签。
- 离场前删除本地临时文件，在交接文档中记录处理过的数据和存放位置。

## 五、出现问题怎么办

- 误把客户数据发到外部群、外部 AI 工具、错误的客户群，或发现 Agent 泄露消费者信息：**立即**按[安全事件上报](security-incident.md)上报，按 P0 处理。
- 客户提出超出 DPA 的数据使用要求（例如“把所有会员手机号导出给我们做营销”）：不要当场答应，转给 CSM 和法务杜明哲评估。

## 违规处理

违反本规范视情节给予警告、降级直至解除劳动合同；造成客户损失或平台处罚的，公司保留追责权利。主动及时上报者从轻处理。
