# 安全事件上报与应急响应

> 文档负责人：信息安全部 白冰｜最近更新：2026-08-15

## 什么情况需要上报

**宁可误报，不可不报。**以下任何情况请立即上报：

- 电脑、手机、工牌丢失或被盗
- 点击了可疑链接、打开了可疑附件、在钓鱼页面输入了密码
- 发现账号异常登录、收到非本人操作的 MFA 推送
- 误把敏感信息发到了外部群、外部邮箱、公开仓库或外部 AI 工具
- 发现代码仓库、配置文件、日志中有明文密钥
- 发现系统漏洞、越权访问、客户数据异常访问
- 收到冒充高管（例如“我是林启航，帮我转账”）的诈骗信息

## 上报后的处理流程

1. **止损**：按安全工程师指导操作，例如立即修改密码、断开网络、IT 远程锁定设备。**不要自己删除证据**。
2. **定级**：信息安全部判定事件等级；涉及个人信息泄露的，按 P0 故障处理，同时通知法务杜明哲评估法定报告义务（《个人信息保护法》要求及时通知监管和受影响个人）。
3. **调查与修复**：信息安全部牵头，相关研发和 SRE 配合。
4. **复盘**：5 个工作日内完成安全事件复盘，改进项录入 Jira（标签 `security`）。

## 密钥泄露专项处理

如果你把密钥、Token、密码提交到了代码仓库或发到了群里：
1. 立即在对应系统**作废/轮换**该密钥（不知道怎么做找 SRE 值班）。
2. 上报信息安全部。
3. 仅删除提交记录是不够的，泄露的密钥必须轮换。

## 钓鱼演练

信息安全部每季度进行钓鱼邮件演练。点击演练链接的同学需要补修 15 分钟的安全课程，不会有其他处罚。识别并上报钓鱼邮件的同学会获得“安全卫士”积分，可兑换礼品。
