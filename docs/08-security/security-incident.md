# 安全事件上报与应急响应

> 文档负责人：信息安全组 白冰｜最近更新：2026-08-15

## 什么情况需要上报

**宁可误报，不可不报。**以下任何情况请立即上报：

- 电脑、手机、工牌丢失或被盗
- 点击了可疑链接、打开了可疑附件、在钓鱼页面输入了密码
- 发现账号异常登录、收到非本人操作的 MFA 推送
- 误把敏感信息发到了外部群、外部邮箱、公开仓库或外部 AI 工具
- 发现代码仓库、配置文件、日志中有明文密钥
- 发现系统漏洞、越权访问、客户数据异常访问
- **Agent 在对话中泄露了消费者信息或其他客户/店铺的数据**，或被 Prompt 注入诱导执行了越权操作
- 电商平台 AppSecret / Access Token、客户系统账号密码疑似泄露
- 驻场时客户设备或客户数据丢失、被拍照外传
- 收到冒充高管（例如“我是冬翔，帮我转账”）的诈骗信息

## 上报后的处理流程

1. **止损**：按安全工程师指导操作，例如立即修改密码、断开网络、IT 远程锁定设备。**不要自己删除证据**。
2. **定级**：信息安全组判定事件等级；**涉及客户数据或消费者个人信息泄露的，一律按 P0 处理**，同时：
   - 通知法务杜明哲评估法定报告义务（《个人信息保护法》要求及时通知监管和受影响个人）及客户合同 / DPA 中的通知义务（通常要求 24 小时内通知客户）
   - 通知技术主管云欢和 CEO 冬翔；由客户 CSM 在法务确认口径后通知客户
   - 涉及电商平台数据的，由白冰评估是否需要向平台报备
3. **调查与修复**：信息安全组牵头，相关研发和 SRE 配合。
4. **复盘**：5 个工作日内完成安全事件复盘，改进项录入 Jira（标签 `security`）。

## 客户数据泄露：你需要做的三件事

1. **立即停止扩散**：撤回消息、停止相关 Agent 意图（切转人工）、断开相关连接。
2. **立即上报**：打安全应急电话 0571-8888-8110，或在“安全应急响应”群 @白冰 / @周子涵，同时告知你的组长。
3. **保留证据**：不要删除日志、会话记录和截图，等待信息安全组指导。

## 密钥泄露专项处理

如果你把密钥、Token、密码提交到了代码仓库或发到了群里：
1. 立即在对应系统**作废/轮换**该密钥（不知道怎么做找 SRE 值班）。
2. 上报信息安全组。
3. 仅删除提交记录是不够的，泄露的密钥必须轮换。

## 钓鱼演练

信息安全组每季度进行钓鱼邮件演练。点击演练链接的同学需要补修 15 分钟的安全课程，不会有其他处罚。识别并上报钓鱼邮件的同学会获得“安全卫士”积分，可兑换礼品。
