# 办公设备与网络使用规范

> 文档负责人：信息安全组 白冰 & IT 主管 江涛｜最近更新：2026-08-15

## 允许

- 在公司电脑上安装 IT 自助门户“软件中心”中的软件
- 合理的个人使用（浏览新闻、个人邮件），不影响工作和安全即可

## 禁止

- 卸载或停用 MDM、EDR、NiuGate 等安全软件
- 安装破解软件、盗版软件、P2P 下载工具、挖矿程序、未经批准的远程控制软件（如向日葵、TeamViewer 个人版）
- 使用个人网盘、个人邮箱传输公司文件
- 私自搭建对外暴露的服务、内网穿透工具（frp、ngrok 等）、代理
- 在公司网络进行端口扫描、渗透测试（经信息安全组授权的安全测试除外）
- 将公司电脑借给他人使用（包括驻场时借给客户人员）
- 在客户提供的设备上登录公司个人账号、或把客户设备上的数据拷贝回公司/个人设备
- 使用未经批准的外部 AI 工具处理公司代码、Prompt 或客户数据（请使用 NiuCopilot）

## 监控说明

为保障信息安全，公司会对公司设备和网络进行安全监控（终端安全日志、网络流量审计、DLP 数据防泄漏），监控范围和方式已在《信息安全承诺书》中告知。公司不会监控个人设备上的个人内容。

## 开源软件使用

- 引入新的开源依赖，需确认许可证（MIT、Apache-2.0、BSD 可直接使用；LGPL 需评估；**GPL/AGPL 需法务审批**）。
- 关注依赖的安全公告，CI 依赖扫描会提示高危漏洞。
