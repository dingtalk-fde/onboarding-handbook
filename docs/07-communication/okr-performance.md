# OKR 与绩效考核

> 文档负责人：HRBP 刘畅、陈晓｜最近更新：2026-06-20

## OKR

- 公司、中心、部门、个人按**季度**制定 OKR，在钉钉“OKR”中公开，**全员可见**。
- 时间线：每季度最后两周制定下季度 OKR → 季度第一周对齐 → 季中回顾 → 季末自评打分（0–1 分）。
- OKR **不直接与绩效挂钩**，鼓励设定有挑战的目标（完成 0.7 即为良好）。
- 新人在入职第 1 个月内制定首个 OKR，可只覆盖剩余季度时间。

## 绩效考核

- **周期**：半年度（6 月、12 月），年度结果为两次的综合。
- **构成**：业绩 70%（结合 OKR 和实际产出）+ 价值观 30%（“云帆四条”）。
- **等级与比例（指导性）**：

| 等级 | 含义 | 参考比例 |
|------|------|----------|
| A | 远超预期 | 10–15% |
| B+ | 超出预期 | 20–25% |
| B | 符合预期 | 50–60% |
| C | 部分未达预期 | 5–10% |
| D | 不符合预期 | 0–5% |

- **流程**：员工自评 → 360 环评（自选 3–5 名合作同事）→ 上级评估 → 部门校准会 → 中心校准会 → 结果沟通（上级 1:1）。
- 入职不满 3 个月的员工不参加当期绩效评估，以试用期评估代替。

## 绩效结果应用

- 年终奖系数、年度调薪、晋升资格都与绩效挂钩。
- 连续两次 C 或一次 D，进入绩效改进计划（PIP）。

## 晋升

- 每年两次（4 月、10 月）晋升评审。
- 资格：当前职级满 1 年，最近一次绩效 B+ 及以上（破格晋升需中心负责人提名）。
- P6→P7 及以上需要晋升答辩，评委由跨部门资深同事组成。
