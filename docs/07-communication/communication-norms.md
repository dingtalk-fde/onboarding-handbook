# 沟通规范与协作习惯

> 文档负责人：人力资源部｜最近更新：2026-07-20

## 工具选择

| 场景 | 工具 | 说明 |
|------|------|------|
| 日常即时沟通 | 钉钉单聊 / 群聊 | 默认渠道 |
| 需要留痕的决策、对外沟通 | 企业邮箱 | 客户、供应商、合作方沟通用邮件 |
| 文档、方案、知识沉淀 | Confluence / 钉钉文档 | 技术文档放 Confluence；轻量协作用钉钉文档 |
| 任务与缺陷 | Jira | 不要用聊天记录追踪任务 |
| 审批 | 钉钉审批 | 所有审批都留在钉钉里，不接受口头审批 |
| 紧急事件 | 电话 + 钉钉“DING” | 仅限紧急情况使用 DING |

## 即时消息礼仪

- **直接说事**：不要只发“在吗？”，把问题、背景和期望一次说清楚。
- **工作时间内 2 小时内回复**；如果正在专注，可以先回复“收到，X 点前回你”。
- 下班后和周末，**非紧急事项不期待即时回复**；紧急事项请打电话。
- 群聊中 @具体的人，慎用 @所有人（只有群主和行政/HR 通知类可以使用）。
- 讨论超过 10 条消息还没结论，改成语音或当面沟通，然后把结论回到群里。
- 敏感话题（绩效、薪酬、个人问题）请单聊或面谈，不要在群里讨论。

## 邮件规范

- 标题写清楚主题，例如：【决策】帆客 BI 3.2 版本发布时间调整
- 正文结论先行，然后是背景和细节。
- 邮件签名格式：

```
姓名 | 职位
星河云帆科技有限公司 NebulaSail
手机：138xxxx | 邮箱：名.姓@nebulasail.example
杭州市余杭区文一西路 998 号 星河云帆大厦
```

- 对外邮件涉及合同、价格、承诺的，抄送直属上级；涉及法律条款的，先找法务杜明哲确认。

## 周报

- 每周五 18:00 前在钉钉“日志”提交周报，模板：本周完成 / 下周计划 / 风险与求助。
- 周报以结果为导向，3–5 条即可，不要求写流水账。
- 直属上级需在下周一前阅读并评论。

## 对外沟通

- 只有市场部和 CEO 办公室授权的人可以代表公司对外发言（媒体、公开演讲、社交媒体）。
- 员工在个人社交媒体发布与公司相关内容，**不得透露未公开的产品、客户、财务信息**，详见[保密规定](../08-security/confidentiality-nda.md)。
- 接到媒体采访请求，转给市场部（pr@nebulasail.example）。
