# IT 设备申请与领用

> 文档负责人：IT 支持部 江涛｜最近更新：2026-09-05｜IT 服务台：杭州 8F（工作日 9:00–19:00），分机 8000

## 新人标准配置

入职前一周，直属上级会在钉钉提交“新人设备申请”，IT 按岗位提前备好设备，**入职当天上午**在 8F IT 服务台领取（北京、深圳由当地行政代发）。

| 岗位 | 电脑 | 显示器 | 其他 |
|------|------|--------|------|
| 研发（后端/前端/移动/SRE/测试/数据） | MacBook Pro 14"，M3 Pro，36GB 内存，1TB | 27" 4K 显示器 × 1（可申请第二台） | 键鼠套装、扩展坞、耳机 |
| 移动端研发 | 同上 | 同上 | 测试机按需从测试机柜借用（孙蕾团队管理） |
| 设计 | MacBook Pro 16"，M3 Max，48GB | 27" 5K 显示器（校色） | 数位板（按需） |
| 产品、职能 | MacBook Air 13"，M3，16GB，512GB | 24" 显示器 × 1 | 键鼠套装 |
| 销售、客户成功 | ThinkPad X1 Carbon 或 MacBook Air（二选一） | 按需 | 便携投屏器 |

- 有 Windows 刚需的研发岗位（如 .NET 客户对接）可申请 ThinkPad P 系列，需部门负责人审批。
- 所有电脑出厂预装：MDM 管理客户端、终端安全（EDR）、SailGate VPN、钉钉。**请勿卸载或停用以上软件**，否则会被自动断开内网访问。

| 第二台显示器、人体工学键鼠 | 直属上级 | 3 个工作日 |

申请入口：钉钉工作台 → “IT 服务台” → “设备申请”。

## 设备更换与维修

- 电脑使用满 **3 年**可申请换新；故障设备送 8F IT 服务台，IT 会提供备用机。
- 设备丢失：**立即**（1 小时内）报告 IT 服务台和信息安全部（security@nebulasail.example），IT 会远程锁定并擦除设备。因个人保管不当丢失的，按折旧后价值赔偿。

## 个人设备（BYOD）

- 个人手机可以安装钉钉和邮箱，需在钉钉中开启“企业安全空间”。
- **禁止**在个人电脑上处理 L3（机密）及以上级别数据，禁止个人电脑连接生产环境，详见[数据分级](../08-security/data-classification.md)。

## 离职归还

离职最后一个工作日，将电脑及所有配件归还 IT 服务台，IT 检查后在离职交接单上签字。电脑数据由 IT 统一擦除，个人资料请提前自行备份（不得包含公司数据）。
