# 行政服务指南（办事指南）

> 文档负责人：行政部 曹敏｜最近更新：2026-09-20

## 常见事项办理

| 事项 | 怎么办 | 办理时间 |
|------|--------|----------|
| 开具在职/收入证明 | 钉钉 → HR 服务台 → “证明开具”，选择用途（签证、贷款等） | 2 个工作日，电子版或 8F 领取纸质版 |
| 工牌丢失补办 | 钉钉 → 行政服务台 → “工牌补办”，工本费 50 元 | 1 个工作日 |
| 访客登记 | 钉钉 → “访客登记”，提前填写访客姓名和手机号，访客凭短信二维码进入 | 即时 |
| 会议室预定 | 钉钉 → “会议室预定” | 即时 |
| 快递收发 | 收件：1F 快递柜，取件码短信通知；寄件（公务）：钉钉 → 行政服务台 → “公务寄件”，顺丰月结 | 每天 16:00 统一揽收 |
| 差旅预订 | 携程商旅（钉钉工作台），见[差旅标准](../04-expenses-benefits/travel-policy.md) | 即时 |
| 工位调整 | 钉钉 → 行政服务台 → “工位申请”，需直属上级审批 | 3 个工作日 |
| 停车 | 大楼地下车库，月租车位需排队申请（目前排队约 3 个月），访客临时停车由行政登记可免 2 小时 | — |
| 名片印制 | 钉钉 → 行政服务台 → “名片申请” | 5 个工作日 |
| 办公用品 | 各楼层文具柜自取；特殊用品通过行政服务台申请 | 即时 / 3 个工作日 |
| 户口/档案 | 公司在杭州人才市场代理档案，找林小满办理 | 视情况 |

## 生活设施（杭州总部）

- **员工餐厅**：大楼 3F，早餐 7:30–9:30，午餐 11:30–13:30，晚餐 17:30–19:30，刷工牌消费，餐补自动充值到餐卡。
- **健身房**：11F，7:00–22:00，免费，需在钉钉签署健身安全承诺书后开通门禁。
- **母婴室**：8F、10F 各一间，冰箱、消毒设备齐全。
- **茶水间**：每层，咖啡机、零食柜（免费）。
- **医务室**：8F，周一至周五 10:00–16:00 有驻场护士，常用药品免费领取。
- **雨伞、充电宝**：8F 前台免费借用。

## 班车

杭州总部提供 3 条通勤班车（城西、滨江、萧山方向），早 8:00 发车，晚 18:45、20:15 两班返程，路线与站点见钉钉“班车查询”。
