# 费用报销制度

> 文档负责人：财务负责人 须莫、费用会计 郑可｜最近更新：2026-08-01｜系统：钉钉费用报销（钉钉工作台 → “钉钉费用报销”）

## 基本规则

1. **先审批，后花钱**：单笔预计超过 2,000 元的支出（差旅除外）需先在钉钉提交“费用申请”，获批后再发生。
2. **发票要求**：必须为增值税发票（电子发票优先），抬头和税号必须正确：
   - 抬头：**Real Niubility（杭州）科技有限公司**
   - 税号：**91330110MA2XXXXX8K**（完整税号见钉钉费用报销首页“开票信息”）
   - 上海、深圳员工同样开总公司抬头
3. **报销时限**：费用发生后 **60 天内**提交报销，逾期需部门负责人和财务负责人须莫特批；超过 180 天不予报销。
4. **截止与付款**：每月 **25 日**为当月报销截止日，审核通过的款项在**次月 10 日**前打入工资卡；25 日后提交的顺延一个月。

## 报销审批链

| 单笔报销金额 | 审批链 |
|--------------|--------|
| < 2,000 元 | 直属上级 → 费用会计郑可审核 → 出纳姚瑶付款 |
| 2,000–10,000 元 | 直属上级 → 部门负责人 → 郑可审核 → 姚瑶付款 |
| 10,000–50,000 元 | 直属上级 → 部门负责人 → 中心负责人 → **财务负责人须莫** → 姚瑶付款 |
| > 50,000 元 | 以上审批 + **CEO 冬翔** |

- 直属上级是第一审批人，负责确认费用的**业务真实性**；财务负责确认**合规性**（发票、标准）。
- 审批人出差时，可在钉钉设置代理审批人。

## 可报销费用类别

| 类别 | 标准 / 说明 |
|------|-------------|
| 差旅（交通、住宿、补助） | 见[差旅标准](travel-policy.md) |
| 业务招待 | 需提前申请，人均 ≤ 300 元（KA 客户 ≤ 500 元），注明客户名称和参与人 |
| 驻场费用 | 驻场期间的交通、住宿、驻场补贴，见[差旅与驻场标准](travel-policy.md)；可向客户转嫁的费用需在报销单勾选“客户项目”并填写项目编号 |
| 模型与云资源 | 个人不得自行购买大模型 API 或云资源报销，统一由 SRE 申请、财务负责人须莫审批 |
| 团建 | 每人每季度 200 元团建经费，由部门负责人统一申请 |
| 办公用品 | 优先走行政统一采购；零星采购单笔 ≤ 200 元可直接报销 |
| 书籍与培训 | 专业书籍每人每年 1,000 元；外部培训/认证需提前申请，详见[福利](benefits-insurance.md) |
| 加班餐、打车 | 见[补贴与津贴](allowances.md) |
| 入职体检 | 上限 300 元 |
| 通讯费 | 销售、客户成功、FDE 岗位每月 200 元（随工资发放，不需报销） |

## 不予报销的情况

- 个人消费（香烟、酒水礼品、私人娱乐）
- 发票抬头/税号错误、连号定额发票、手写发票
- 无业务说明或业务说明与发票明显不符
- 违反差旅标准的超标部分（特批除外）

## 借款（备用金）

出差或活动预计费用超过 5,000 元的，可在钉钉提交“借款申请”，审批链同报销，出纳姚瑶在 2 个工作日内打款。借款需在活动结束后 **30 天内**报销冲账。

## 报销常见问题

- **发票丢了怎么办？** 电子发票可重新下载；纸质发票丢失的，需找开票方开具发票复印件并加盖发票专用章，另附情况说明，由郑可审核。
- **报销被退回？** 钉钉费用报销中会写明退回原因，按要求修改后重新提交即可。不清楚的直接钉钉郑可。
- **外币发票？** 附信用卡账单，按刷卡当日汇率折算。
