# 部门职责说明

> 文档负责人：HR 负责人 辰驷｜最近更新：2026-10-01

## 技术中心（技术主管 云欢，约 95 人）

### FDE 交付部（总监 韩东，约 50 人）
按行业分三个 FDE 组，每组同时服务 3–6 个客户：
- **服饰美妆 FDE 组（组长 钱程）**：女装、运动、美妆个护品牌和服务商；尺码推荐、售后客服、种草内容 Agent 经验最丰富。
- **食品快消 FDE 组（组长 苏晴）**：零食、乳品、酒水、日化；大促客服峰值、临期与批次售后、直播话术。
- **3C 家电 FDE 组（组长 罗伊）**：手机配件、小家电、大家电；参数问答、安装与保修工单、以旧换新。

FDE 的职责：Discovery、PoC 实施、客户系统集成、Agent 搭建（Prompt / 工具 / 知识库）、评测与上线、上线后效果运营、客户现场支持。

### Agent 平台部（负责人 马骁，约 22 人）
- NAP 运行时（Agent 编排、工具调用、会话记忆、HITL 审核流）
- **电商平台连接器**：淘宝开放平台、京东宙斯、抖店开放平台、拼多多开放平台、千牛/京麦/飞鸽客服接入
- 模型网关（多模型路由、脱敏、审计、成本统计）、知识库与 RAG 组件
- 客户控制台（Agent 配置、效果看板）

### 数据与评测组（组长 许蔓，约 10 人）
- NEval 评测中心：评测集管理、回归评测、LLM-as-judge 与人工评测
- 标注团队管理与标注规范；客户数据脱敏管道

### SRE 组（组长 雷鸣，约 5 人）
- 阿里云、聚石塔、京东云鼎、抖音电商云、多多云上的部署环境
- 监控告警、容量（大促峰值）、故障指挥（IC 轮值）、生产权限最终审批

### 质量与效能组（组长 孙蕾，约 5 人）
- 测试策略、CI 流水线模板、Launchpad 发布规则与发布窗口

### 信息安全组（负责人 白冰，约 3 人）
- 安全制度、客户数据安全、权限审计、ISO 27001 合规、平台数据安全审核（聚石塔等）
- 安全事件应急响应、员工与驻场安全培训

## 解决方案与产品中心（负责人 梁宛，约 18 人）
- **SA 团队（方哲）**：售前方案、Discovery、PoC 设计与验收标准、SOW 范围
- **Agent 产品团队（宋雨桐、程可欣、魏然）**：标准化 Agent 产品（客服、商品、内容、售后、分析）与 NAP 产品规划
- **体验设计（唐糖）**：客户控制台和 Agent 对话体验设计

## 商业化中心（VP 邓伟，约 25 人）
- **销售部**：华东大区（彭浩，含杭州、上海）、华南大区（关芸，深圳、广州）
- **客户成功部（黄佳怡）**：客户上线后的关系维护、续约增购、NPS、客户问题升级到 FDE 的唯一入口

## 财务与法务中心（财务负责人 须莫，约 6 人）
- 财务：预算、报销审核（郑可）、付款（姚瑶）、发票、薪资发放、客户回款
- 法务（杜明哲）：客户合同与 SOW、**客户数据处理协议（DPA）**、NDA、知识产权、劳动法务

## 人力与行政中心（HR 负责人 辰驷，约 12 人）
- HRBP（刘畅）、招聘与入职（林小满）、薪酬福利与社保（杨帆）
- 行政（曹敏）：办公环境、工位、门禁、会议室、差旅预订（携程商旅）、驻场住宿安排
- IT 支持（江涛）：电脑与外设、办公账号、NiuGate、IT 服务台、软件 License 采购

> 注意区分：**办公类账号**（钉钉、邮箱、VPN）找 IT 支持；**研发与客户环境权限**（GitLab、NAP 生产、聚石塔、客户系统账号）走研发权限流程，见[研发系统权限开通](../05-it-access/dev-access.md)。
