# 管理层与决策机制

> 文档负责人：CEO 办公室｜最近更新：2026-10-01

## 管理委员会（MC）

成员：冬翔（CEO，主席）、云欢（技术主管）、须莫（财务负责人）、辰驷（HR 负责人）、梁宛（解决方案与产品）、邓伟（商业化 VP）。

- **周会**：每周一 9:30–11:00，审视客户交付健康度（红黄绿灯）、新签与续约、现金流、风险。
- **季度会**：确定下季度 OKR、预算和招聘计划（HC）。

## 决策授权（简化版）

| 事项 | 发起 | 决策人 |
|------|------|--------|
| 项目内技术方案 | FDE | FDE 组长；涉及 NAP 平台改动需马骁同意 |
| 新增 HC | 部门负责人 | 中心负责人 + HR 负责人辰驷；超预算需 CEO 冬翔 |
| 接受一个新 PoC | SA | 方哲 + FDE 交付部总监韩东（评估人力） |
| 免费 PoC 超过 4 周或投入 > 3 人月 | SA | CEO 冬翔 + 技术主管云欢 |
| SOW 报价与付款条件 | 销售 / SA | 商业化 VP 邓伟 + 财务负责人须莫 |
| 客户合同、DPA 非标条款 | 销售 | 法务杜明哲 + 财务负责人须莫；重大风险条款需 CEO |
| 单笔采购 < 1 万 | 申请人 | 部门负责人 |
| 单笔采购 ≥ 1 万 | 申请人 | 部门负责人 + 财务负责人须莫；≥ 20 万需 CEO |
| 使用新的大模型供应商 / 新的外部数据处理方 | 技术 | 技术主管云欢 + 信息安全负责人白冰 + 法务 |
| 生产重大变更（P0 风险） | 研发 | SRE 组长雷鸣 + 技术主管云欢 |

## 架构评审委员会

- 召集人：沈默；成员：云欢、马骁、韩东、许蔓、雷鸣、白冰。
- 触发条件：NAP 新组件、新连接器、跨客户复用组件、引入新的模型或数据存储、涉及 L3 及以上客户数据的方案。
- 会议：每周三 15:00–16:00，议题提前一天提交到 Confluence “架构评审”空间。

## 如何向上反馈

- 日常问题：先和直属上级 1:1 沟通。
- 跨级反馈：预约 CEO 冬翔或技术主管云欢的 “Open Door” 时间（每周四下午，钉钉日程预约）。
- 匿名反馈：钉钉“RN 心声”匿名问卷，HR 负责人辰驷每月汇总回复。
- 违规举报：compliance@realniubility.example，由法务独立处理，严格保密。
