# 管理层与决策机制

> 文档负责人：CEO 办公室｜最近更新：2026-06-30

## 经营管理委员会（EMC）

成员：林启航（CEO，主席）、周砚（CTO）、梁宛（CPO）、邓伟（商业化 VP）、吴秀兰（CFO）、王静怡（HRVP）、陈思远（COO）。

- **周会**：每周一 9:30–11:30，审视上周经营数据、重大客户、风险事项。
- **季度会**：每季度最后两周，确定下季度 OKR、预算和人力规划（HC）。

## 决策授权（简化版）

| 事项 | 发起 | 决策人 |
|------|------|--------|
| 部门内技术方案 | 工程师 | 组长；跨组影响需架构评审委员会 |
| 新增 HC（招聘名额） | 部门负责人 | 中心负责人 + HRVP；超出年度预算需 CEO |
| 单笔采购 < 5 万 | 申请人 | 部门负责人 + 采购部 |
| 单笔采购 5–50 万 | 申请人 | 中心负责人 + CFO |
| 单笔采购 > 50 万 | 申请人 | CEO |
| 产品路线图 | 产品部 | CPO 梁宛，季度会确认 |
| 对外发布重大功能 / 公关稿 | 产品/市场 | CPO + CEO，法务杜明哲审核 |
| 生产环境重大变更（P0 风险） | 研发 | SRE 组长雷鸣 + 所在研发总监 |

## 架构评审委员会

- 召集人：沈默；成员：韩东、赵一鸣、马骁、许蔓、雷鸣、白冰。
- 触发条件：新增服务、跨团队接口变更、引入新的中间件或数据库、涉及 L3 及以上数据的存储方案。
- 会议：每周三 15:00–16:00，议题需提前一天在 Confluence “架构评审”空间提交。

## 如何向上反馈

- 日常问题：先和直属上级 1:1 沟通。
- 跨级反馈：可以直接预约中心负责人的“Open Door”时间（每周四下午，钉钉日程预约）。
- 匿名反馈：钉钉“云帆心声”匿名问卷，HRVP 王静怡每月汇总回复。
- 违规举报：compliance@nebulasail.example，由法务合规部独立处理，严格保密。
