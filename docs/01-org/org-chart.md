## 二、四位关键负责人

| 角色 | 姓名 | 管什么 | 新人什么时候会找他/她 |
|------|------|--------|----------------------|
| CEO | **冬翔** | 公司战略、重大客户、融资 | 双月全员会、Open Door 时间 |
| 技术主管（技术中心负责人） | **云欢** | 技术中心全部团队、技术路线、交付质量 | 架构评审终审、P0 故障通报、研发 P8+ 转正 |
| 财务负责人 | **须莫** | 财务、预算、报销终审、法务 | 单笔 ≥ 1 万元报销、采购与合同付款 |
| HR 负责人 | **辰驷** | 招聘、HR、薪酬福利、行政与 IT | 转正终审、劳动合同、员工关系 |

## 三、汇报关系要点

- 每位员工**只有一个直属上级**（钉钉通讯录中“主管”字段），请假、报销、转正等审批默认先到直属上级。
- FDE 组长向 FDE 交付部总监韩东汇报；韩东、马骁、许蔓、雷鸣、孙蕾、白冰向技术主管云欢汇报。
- 信息安全负责人白冰在客户数据安全事项上可**直接向 CEO 冬翔汇报**（虚线）。
- 法务经理杜明哲行政上向财务负责人须莫汇报，合同审批中独立出具意见。
- 行政（曹敏）和 IT 支持（江涛）归属人力与行政中心，向辰驷汇报。

## 四、矩阵协作：客户项目组

每个客户项目由一个**项目铁三角**负责：
- **FDE 负责人**（来自对应行业 FDE 组）：技术交付与 Agent 效果
- **SA**（来自方哲团队）：方案、PoC 设计、范围控制
- **CSM**（来自黄佳怡团队）：客户关系、续约、满意度

Agent 平台部为所有项目提供平台能力；平台缺失的能力由 FDE 提需求到马骁团队，或在项目中先实现后反哺平台（“先交付，后沉淀”）。
