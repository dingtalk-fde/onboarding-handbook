# 工作时间与考勤

> 文档负责人：薪酬福利主管 杨帆｜最近更新：2026-07-01｜依据《云帆员工手册》第 5 章

## 工时制度

公司实行**弹性工时制**，每日标准工作时长 **8 小时**（不含午休），每周 5 天。

| 项目 | 规定 |
|------|------|
| 最早上班打卡 | 8:00 |
| **核心工作时间** | **10:00–12:00、13:30–16:00**（必须在岗或在线） |
| 午休 | 12:00–13:30（不计入工时） |
| 最晚上班打卡 | 10:00（超过 10:00 计为迟到） |
| 下班 | 上班打卡时间 + 9.5 小时（含 1.5 小时午休）之后 |

> 例：9:20 上班打卡，18:50 之后即可下班打卡。

销售、客户成功等外勤岗位实行**综合工时制**，以钉钉外勤打卡 + CRM 拜访记录为准，由所在大区总监审核。

## 打卡方式

- 使用**钉钉“考勤打卡”**，在公司 Wi-Fi（SSID：NebulaSail-Office）或办公楼 200 米范围内打卡。
- 每天打卡两次：上班、下班。
- 忘记打卡：在钉钉提交“补卡申请”，**每月最多 3 次**，由直属上级审批。超过 3 次的缺卡按事假半天处理。

## 迟到、早退与缺勤

| 情况 | 处理 |
|------|------|
| 迟到 ≤ 30 分钟 | 每月前 3 次不处理（“弹性豁免”），第 4 次起每次扣 50 元 |
| 迟到 > 30 分钟 | 未提前请假的，按事假 0.5 天处理 |
| 早退 | 工时不足 8 小时且未请假，按事假处理 |
| 旷工 | 未请假且未出勤，按旷工处理；连续旷工 3 天或一年累计 5 天，视为严重违纪 |

## 远程办公（WFH）

- 每位员工**每月可申请最多 4 天**远程办公，需提前 1 天在钉钉提交“远程办公申请”，直属上级审批。
- 远程办公期间：核心工作时间内钉钉保持在线，30 分钟内回复消息；必须开启 SailGate VPN 访问内网。
- 试用期前 1 个月原则上不安排远程办公。
- 恶劣天气（台风、暴雪橙色预警以上）由行政部统一发布全员 WFH 通知。

## 节假日

- 按国务院公布的法定节假日放假和调休，行政部每年 12 月发布下一年的放假安排。
- 公司额外福利假：**生日假 1 天**（生日当月内使用）、**年会日下午**。

## 考勤异常查询

钉钉 → 考勤打卡 → 统计，可查看个人月度考勤。每月 3 日前 HR 会推送上月考勤确认单，有异议请在 5 日前找杨帆。
