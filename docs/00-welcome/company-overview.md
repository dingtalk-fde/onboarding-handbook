# 公司简介：Real Niubility

## 我们是谁

**Real Niubility（杭州）科技有限公司**（内部简称 **RN**）成立于 2022 年，总部位于杭州，是一家**为电商企业定制垂直 AI Agent 的 FDE（Forward Deployed Engineer，前置部署工程师）公司**。

我们不卖“通用聊天机器人”。我们的 FDE 工程师深入客户的业务现场（很多时候直接驻场），把客户的商品、订单、客服、营销和经营数据接入我们自研的 **Niubility Agent Platform（NAP）**，交付真正能在生产环境里干活、可度量、可持续优化的 AI Agent。

- 使命：**让每个电商团队都有一支不知疲倦的 AI 员工队伍。**
- 员工规模：约 **160 人**（截至 2026 年 9 月），其中技术中心约 95 人（FDE 约 50 人）
- 融资阶段：A+ 轮（2025 年完成）
- 客户：60+ 家付费客户，以**品牌商家**和**电商代运营服务商（TP）**为主，覆盖服饰美妆、食品快消、3C 家电三大行业
- 主要渠道：淘宝/天猫、京东、抖音电商、拼多多，以及客户自有小程序商城

## 我们交付的 Agent

| Agent | 解决什么问题 | 典型指标 |
|-------|-------------|---------|
| 智能客服 Agent | 售前咨询、尺码推荐、售后政策解答，接入千牛、京麦、抖店飞鸽、拼多多商家后台客服工作台 | 自动解决率、转人工率、违规承诺率（必须为 0） |
| 商品运营 Agent | 商品上架、标题与卖点生成、属性补全、类目合规检查、多平台同步 | 上架时效、类目/资质违规数 |
| 营销内容 Agent | 主图文案、详情页、种草笔记、短视频脚本、直播话术 | 内容采纳率、点击率提升 |
| 订单与售后 Agent | 物流异常预警、退换货审核建议、仅退款风险识别、催发货 | 售后处理时长、误判率 |
| 经营分析 Agent | 对接生意参谋、京东商智、抖店罗盘等数据，自动生成日报周报与异动归因 | 报表时效、归因准确率 |

## 业务模式

1. **Discovery 诊断（1–2 周）**：FDE + 解决方案架构师到客户现场梳理流程、数据和指标。
2. **PoC（2–4 周）**：在客户真实数据上（经客户授权、在合规环境中）跑通一个 Agent，并用双方约定的评测集证明效果。
3. **交付上线（4–8 周）**：签署 SOW 后，FDE 小组完成集成、灰度和上线。
4. **持续运营**：按月订阅收费，FDE 继续负责 Agent 的效果优化和 SLA。

## 发展历程

- 2022：冬翔与云欢在杭州创立 Real Niubility，第一个客户是一家女装品牌的天猫店铺客服 Agent
- 2023：天使轮；发布 Niubility Agent Platform 1.0；客户数突破 10 家
- 2024：A 轮；成立上海办公室；通过 ISO 27001 认证；完成聚石塔、京东云鼎的合规部署
- 2025：A+ 轮；上线评测中心 NEval；成立深圳办公室，拓展抖音电商与拼多多客户
- 2026：付费客户 60+；单月 Agent 处理消费者会话超 3,000 万次
