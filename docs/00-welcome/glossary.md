# 常用术语与缩写表

> 新人最常问“这个词是什么意思”。不在列表里的词，欢迎在钉钉群“RN 新人营”提问，或对本仓库提 PR 补充。

## 公司与业务

| 术语 | 含义 |
|------|------|
| RN | Real Niubility 的内部简称 |
| **FDE** | Forward Deployed Engineer，前置部署工程师。既写代码又懂业务，深入客户现场把 Agent 落地到生产的工程师，是公司的核心岗位 |
| FDE 小组 | 按行业（服饰美妆 / 食品快消 / 3C 家电）组织的交付小组，一个小组同时服务 3–6 个客户 |
| 驻场 | FDE 到客户办公室连续工作，通常 1–4 周，详见[差旅与驻场标准](../04-expenses-benefits/travel-policy.md) |
| SA | Solution Architect，解决方案架构师，负责售前方案与 PoC 设计 |
| Discovery | 需求诊断阶段，梳理客户流程、数据与指标 |
| **PoC** | Proof of Concept，概念验证，在客户真实数据上用评测集证明 Agent 效果，一般 2–4 周 |
| SOW | Statement of Work，工作说明书，PoC 通过后与客户签署，明确交付范围、验收标准和 SLA |
| 品牌商家 / TP | 我们的两类客户：自营店铺的品牌方；为品牌代运营店铺的服务商（Taobao Partner 等） |
| KA | 重点客户，年合同额 100 万以上 |
| CSM | 客户成功经理 |

## AI / Agent 技术

| 术语 | 含义 |
|------|------|
| **Agent** | 能理解目标、调用工具（如查订单、改商品、发优惠券）并多步完成任务的 AI 系统 |
| NAP | Niubility Agent Platform，公司自研 Agent 平台：运行时、工具连接器、知识库、评测、发布 |
| 工具 / Tool | Agent 可以调用的能力，例如“查询订单物流”“生成商品标题”，在 NAP 中登记并有权限控制 |
| 连接器 | 对接电商平台开放 API 的组件：淘宝开放平台（TOP）、京东宙斯、抖店开放平台、拼多多开放平台 |
| **Prompt** | 给大模型的指令。在 RN，Prompt 和代码一样需要版本管理、Code Review 和评测 |
| **RAG** | 检索增强生成：先从客户知识库（商品资料、售后政策）检索，再让模型基于检索结果回答 |
| **Eval / 评测** | 用标注好的评测集对 Agent 打分。任何 Prompt、模型、工具变更上线前都要过评测门禁 |
| NEval | 公司评测中心，管理评测集、跑回归评测、出报告 |
| 评测集 / Golden Set | 与客户共同确认的标准问答或任务集合，PoC 验收和上线回归都以它为准 |
| Guardrail | 护栏规则，例如禁止承诺“假一赔十”、禁止泄露消费者信息、退款金额超阈值需人工确认 |
| HITL | Human-in-the-loop，人工兜底审核，高风险动作必须有人确认 |
| 模型网关 | 统一接入通义千问、DeepSeek、豆包等模型的内部网关，负责脱敏、审计、限流和成本统计 |
| Badcase | Agent 回答错误或处理失败的案例，需要录入 NEval 并纳入回归 |

| 术语 | 含义 |
|------|------|
| 聚石塔 | 阿里官方电商云环境。**淘宝/天猫订单数据必须在聚石塔内处理** |
| 京东云鼎 / 抖音电商云 / 多多云 | 京东、抖音、拼多多各自要求的合规部署环境 |
| 千牛 / 京麦 / 飞鸽 | 淘宝、京东、抖店的商家客服工作台 |
