# 常用术语与缩写表

> 新人最常问“这个词是什么意思”。不在列表里的词，欢迎在钉钉群“云帆新人营”提问，或直接补充本页（提 MR 到本仓库）。

| 术语 | 含义 |
|------|------|
| 云帆 | 公司内部简称 |
| 帆客 | 公司产品品牌，含帆客 CRM、帆客 BI、帆客导购 |
| 小帆 | 2025 年发布的 AI 经营助手 |
| 帆舟（Sailboat） | 内部发布平台，所有生产发布必须走帆舟 |
| SailGate | 公司零信任 VPN 客户端，访问内网系统必须开启 |
| 帆账 | 财务费用系统，与钉钉审批打通 |
| HRBP | 业务部门对接的 HR，技术中心 HRBP 为刘畅，产品/商业化 HRBP 为陈晓 |
| Buddy | 新人入职伙伴，负责新人前 3 个月的日常答疑 |
| 导师（Mentor） | 负责新人业务成长的资深同事，通常是直属上级指定 |
| 1:1 | 与直属上级的一对一沟通，每两周至少一次 |
| OKR | 目标与关键结果，按季度制定，详见[OKR 与绩效](../07-communication/okr-performance.md) |
| P 级 / M 级 | 专业序列 P4–P10，管理序列 M1–M4 |
| MR | Merge Request，代码合并请求（我们用自建 GitLab） |
| 封网 | 禁止生产变更的时间窗口 |
| P0/P1/P2/P3 | 故障等级，详见[On-call 与故障处理](../06-engineering/oncall-incident.md) |
| CR | Code Review，代码评审 |
| PRD | 产品需求文档 |
| ISV | 独立软件开发商，开放平台的合作伙伴 |
| KA | 重点大客户（Key Account），年合同额 50 万以上 |
| CSM | 客户成功经理 |
| L1–L4 | 数据密级：公开、内部、机密、绝密 |
| 远航厅 | 杭州 8F 大会议室，可容纳 150 人 |
