# 企业文化与价值观

> 文档负责人：人力与行政中心 辰驷（HR 负责人）｜最近更新：2026-07-01

## 使命、愿景

- **使命**：让每个电商团队都有一支不知疲倦的 AI 员工队伍。
- **愿景**：成为电商行业最值得信赖的 AI Agent 交付伙伴。

## 四条价值观（“RN 四条”）

1. **客户第一，结果说话**：Agent 上线后的真实指标（解决率、时效、GMV）才是结果。Demo 漂亮不算数，评测和生产数据说了算。
2. **坦诚清晰**：有问题当面说、写清楚；反对意见要在决策前提出，决策后全力执行（Disagree and commit）。
3. **主人翁精神**：发现问题不绕过、不甩锅；“这不是我的事”在 RN 不成立，至少要把问题交到对的人手上。
4. **持续学习**：鼓励分享和复盘，失败可以，重复犯同样的错误不行。

价值观占绩效考核的 30%，在试用期评估和年度绩效中都会评价。

## 日常文化

- **扁平称呼**：所有人互相直呼名字或花名，不叫“X 总”“X 老师”，包括 CEO 冬翔。
- **周五分享会（Friday Talk）**：每周五 16:30–17:30，在 5F 大会议室“远航厅”，同时钉钉直播，分享主题不限。
- **双月全员会（All Hands）**：每两个月一次，由 CEO 主持，公开经营数据和重大决策，设匿名提问环节。
- **生日会与节日活动**：每月最后一个周四下午茶 + 当月生日会；端午、中秋、年会由行政统一组织。
- **年会**：每年 1 月中旬举行，设“RN 之星”“最佳协作奖”等奖项。

## 我们不鼓励的行为

- 用职级压人、开会只听职级最高的人说话
- 在背后议论同事、在公开群里指责个人
- 无意义的“表演式加班”
- 未经允许对外透露客户和公司信息（详见[保密规定](../08-security/confidentiality-nda.md)）
