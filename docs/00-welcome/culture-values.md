# 企业文化与价值观

> 文档负责人：人力资源部 王静怡（HRVP）｜最近更新：2026-07-01

## 使命、愿景

- **使命**：让每一家门店都拥有数据驱动的经营能力。
- **愿景**：成为中国零售行业最值得信赖的经营操作系统。

## 四条价值观（“云帆四条”）

1. **客户第一，结果说话**：所有讨论都要回到“对客户有什么价值”。我们看结果，不看加班时长。
2. **坦诚清晰**：有问题当面说、写清楚；反对意见要在决策前提出，决策后全力执行（Disagree and commit）。
3. **主人翁精神**：发现问题不绕过、不甩锅；“这不是我的事”在云帆不成立，至少要把问题交到对的人手上。
4. **持续学习**：鼓励分享和复盘，失败可以，重复犯同样的错误不行。

价值观占绩效考核的 30%，在试用期评估和年度绩效中都会评价。

## 日常文化

- **扁平称呼**：所有人互相直呼名字或花名，不叫“X 总”“X 老师”，包括 CEO 林启航。
- **周五分享会（Friday Talk）**：每周五 16:30–17:30，在 8F 大会议室“远航厅”，同时钉钉直播，分享主题不限。
- **双月全员会（All Hands）**：每两个月一次，由 CEO 主持，公开经营数据和重大决策，设匿名提问环节。
- **生日会与节日活动**：每月最后一个周四下午茶 + 当月生日会；端午、中秋、年会由行政部统一组织。
- **年会**：每年 1 月中旬举行，设“云帆之星”“最佳协作奖”等奖项。

## 我们不鼓励的行为

- 用职级压人、开会只听职级最高的人说话
- 在背后议论同事、在公开群里指责个人
- 无意义的“表演式加班”
- 未经允许对外透露客户和公司信息（详见[保密规定](../08-security/confidentiality-nda.md)）
